# 「住まいの対話」コンセプト整理

宣伝文の土台になる言葉を先に固定します。ここがブレると投稿ごとに印象が変わり、認知が積み上がりません。

## ひとことで言うと

> 図面を描く前に、暮らしの話をする。HANDS-A-DESIGN の家づくりは「打ち合わせ」ではなく「対話」から始まります。

## 名前が持っている強み

「住まいの対話」という名称は、それ自体がすでにメッセージになっています。

- **対話** … 一方通行の提案でも、要望の聞き取りでもない。行き来がある
- **住まい** … 「家」「住宅」より生活の手触りが近い。建物ではなく暮らしの話だと伝わる
- 売り込みの匂いがしない。だから**認知拡大フェーズと相性が良い**

宣伝でやるべきは「新しい売り文句を足すこと」ではなく、**この名前の意味を一つずつ具体で見せること**です。

## 3つの柱（投稿のネタ元）

1. **図面より先に、暮らしの話をする**
   - 何帖ほしいかより、朝どこで何をしているか
2. **決めることを急がせない**
   - 「まだ建てるか決めていない」段階の相談を歓迎する
3. **迷いも含めて残す**
   - 意見が割れたこと、変わった考えも記録して、後から辿れるようにする

## キャッチコピー案

短い順。画像1枚目やプロフィール文に使えます。

- 図面の前に、話をしよう。
- 家は、話し終えてから建てはじめる。
- 「なんとなく好き」を、言葉にするところから。
- 正解を出す前に、問いをそろえる。
- 住まいの答えは、住む人の中にあります。
- 建てる前に、話し足りないことはありませんか。

**推し**：`図面の前に、話をしよう。` — 短く、名称の説明になっていて、行動（話す）を含んでいます。

## プロフィール文案（150字）

```
【エリア】で設計をしている HANDS-A-DESIGN です。
図面を描く前に、暮らしの話をじっくり聞く「住まいの対話」から家づくりを始めています。
まだ建てるか決めていない段階のご相談も歓迎です。
#住まいの対話
```

## 言わないこと

認知拡大フェーズでは、以下を投稿に混ぜないほうが効きます。

- 「今なら無料」「限定」などの煽り
- 施工実績数・受賞歴の羅列（信頼づくりは後のフェーズ）
- 他社批判（「よくあるハウスメーカーは…」）
- 毎回の「お問い合わせはこちら」— 3回に1回で十分

## 届けたい人

- 家づくりを考え始めたが、まだ何も決まっていない人
- 住宅展示場に行って、話が早すぎて疲れた人
- 夫婦・家族で意見がまとまらず止まっている人
- リノベーションか建て替えかで迷っている人

いずれも**「まだ相談する段階じゃない」と自分で思っている人**です。投稿の役割は、その思い込みを外すことです。
