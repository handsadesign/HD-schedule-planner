# 「住まいの対話」SNS投稿文セット

目的は**認知拡大**。売り込みではなく「こういう考え方の設計事務所がある」と覚えてもらうことを狙います。
そのため CTA（申込導線）は弱め、代わりに**保存・共有されやすさ**を優先しています。

---

## Instagram：フィード投稿（5本）

各投稿に「1枚目に載せる文言」を付けています。文字は大きく、1枚目は**1文だけ**にしてください。

### ① 名前の説明（最初に出す1本）

**1枚目の文言**
> 図面の前に、話をしよう。

**本文**
```
HANDS-A-DESIGN の家づくりは、図面から始まりません。

まず「住まいの対話」という時間をとります。
何帖の部屋がほしいか、ではなく
朝いちばんにどこにいるか。
休みの日、いちばん長く座っている場所はどこか。
そんな話を、ひたすら聞くところから始めます。

要望をまとめるための聞き取りではありません。
話しているうちに、ご本人も気づいていなかった
「うちの暮らし方」が出てくる。
その先に、はじめて図面があります。

家は、話し終えてから建てはじめる。
そう思っています。

#住まいの対話
```

**本文**
```
ご相談でいちばん多い前置きが、これです。

「まだ全然決まっていなくて」
「土地も見てないんですけど」
「相談していい段階か分からなくて」

決まっていないから、話す意味があります。

決まってから来られると、
もう選択肢がいくつか消えていることがあります。
土地を買ったあとでは変えられないこと、
間取りを描いたあとでは戻れないこと。
その手前で一度話せると、選べる幅がまるで違います。

「住まいの対話」は、
決めるための場ではなく、迷いを並べる場です。

まだ何も決まっていない、という方こそどうぞ。

#住まいの対話
```

### ③ 具体の質問を見せる（保存されやすい型）

**1枚目の文言**

**本文**
```
「住まいの対話」で実際にお聞きしていることから、
ご家族だけでも話せるものを5つ。

1. 朝、起きてから家を出るまでの動きを、順番に言えますか
2. 家の中で、いちばん長く座っている場所はどこですか
3. 今の住まいで、いちばん不便なのはどこですか
4. 10年後、この家に何人で住んでいると思いますか
5. お互いが「これだけは譲れない」と思っていることを、知っていますか

5番でだいたい、意見が割れます。
割れて大丈夫です。むしろ、建てる前に割れたほうがいい。

答えが出なくても、
「ここが違うんだね」と分かっていることが、
のちのち効いてきます。

保存して、時間のあるときにどうぞ。

#住まいの対話
```

> ※この型（質問リスト・チェックリスト）は保存率が高く、認知拡大フェーズの主力になります。月1本は入れてください。

```
【実例】

出てきたのは
『【　　　　】』
という言葉でした。

そこから話が変わりました。

要望をそのまま形にすることが、
いつも正解とは限りません。
だから、話します。

#住まいの対話
```

> ※ここは**必ず実際のエピソードに差し替えて**ください。作った話を載せると、この取り組み全体の信用が落ちます。お客様の許可も忘れずに。

## Facebook：3本

Instagram より年齢層が上がる想定で、丁寧め・長めにしています。

**F1（サービス紹介）**
```
HANDS-A-DESIGN では、家づくりのはじめに「住まいの対話」という時間を設けています。

図面をお見せする前に、今の暮らしについて伺う時間です。
何帖の部屋が必要か、ではなく、朝どこで過ごしているか。休みの日にいちばん長くいる場所はどこか。そうした話を、ゆっくりお聞きします。

ご要望をまとめるための聞き取りではありません。話しているうちに、ご本人も気づいていなかった「わが家の暮らし方」が出てくることがあります。そこからはじめて、図面に取りかかります。

まだ建てるかどうか決めていない、土地も探していない——そういった段階でのご相談がいちばん多いです。どうぞお気軽にお声がけください。

【エリア】｜【相談方法】
```

**F2（読みもの型）**
```
「建てる前に、夫婦で意見が割れたほうがいい」

打ち合わせでよく申し上げることです。

家づくりを進めていると、どこかで必ず意見が分かれます。多いのは、収納の量と、来客のためのスペース。片方が「絶対いる」と言い、もう片方が「使わない」と言う。

このとき、その場で結論を出さなくて構いません。大事なのは、お互いが何を大事にしているかが見えることです。「収納がほしい」の裏に、片づけられない家で育った記憶があったりします。理由まで分かると、落としどころは自然と見つかります。

割れたまま建ててしまうと、住み始めてから同じ話がまた出てきます。建てる前のほうが、ずっと安全です。

#住まいの対話
```

**F3（軽い1本）**

```
遠回りに見えるかもしれませんが、この時間があると、あとの打ち合わせの回数が減ります。何を大事にしたいかが決まっているので、迷う時間が短くなるためです。

「住まいの対話」と呼んでいます。
```
