# 「住まいの対話」宣伝用ドキュメント

目的：**認知を広げる**（申込獲得は次のフェーズ）

## サービス概要

**住まいの対話** — https://sumai-dialogue.com

AIの聞き手と話しながら、自分の暮らしの価値観を整理していくウェブサービス。
最後に「**暮らしと住まいの要望書**」という一冊にまとまる。スマートフォン・パソコン両対応。

- 所要時間：一気に進めれば1時間ほど。中断して後日、続きから再開できる
- できあがった要望書は**対話をした方のもの**。HANDS-A-DESIGN に持ってきても、他の設計者・工務店との打ち合わせに使っても、誰にも見せなくてもよい
- サービス内から HANDS-A-DESIGN への誘導は一切なし。話した内容が HANDS-A-DESIGN に届くこともない
- 対話の記録はサーバーに保存されず、**本人の端末内にのみ残る**

### つくった理由

1. **ヒアリングの非対称を埋めるため。** 「どんな家にしたいですか？」に即答できる人はほとんどいない。一生に一度の家づくりで、考える練習をする機会がないまま打ち合わせの席に着くため。加えて設計者は言葉を多く持ち、住む方は初めて。同じテーブルでも会話は設計者側に傾く。会う前に、住む方の側に言葉を用意してもらう
2. **遠方の相談に応えるため。** 岡山・兵庫・愛知などから相談を受けても、建築は場所に根ざす仕事のため応えられなかった。建てる責任から離れ、ヒアリングで培った経験と知識だけなら距離を越えて届けられる

### 根っこにある考え

> 住まい手が、つくり手と対等に話せるようになること。それ自体が、良い家づくりの一番の土台。

## 改訂が必要なファイルについて

`concept.md` / `sns-posts.md` は、サービスの実態が共有される前に**名称からの推測で書いたもの**です。
「対面のヒアリングの進め方」を前提にしているため、実際の「ウェブサービス」とは前提がずれています。

そのまま投稿せず、以下のいずれかで扱ってください。

- サービス紹介として使うなら、`instagram-post.md` と本README の内容に沿って全面的に書き直す
- 「設計事務所としての家づくりの姿勢」を伝える投稿としてなら、内容自体は流用できる（ただし `#住まいの対話` はサービス名なので、混同を避けるためタグの使い分けを決めること）

なお `sns-posts.md` のInstagram④は**架空のエピソード枠**です。実話に差し替えない限り使わないでください。

`posting-plan.md` の運用ルール・指標・ネタ切れ対策は前提に依存しないため、そのまま使えます。
