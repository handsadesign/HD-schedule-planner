# 「住まいの対話」宣伝用ドキュメント

目的：**認知を広げる**（申込獲得は次のフェーズ）
成果物：SNS投稿文セット（Instagram / X / Facebook）

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `concept.md` | 「住まいの対話」の言語化・キャッチコピー案・伝えないことの整理 |
| `sns-posts.md` | 投稿文セット本体（Instagram 5本／ストーリーズ 4本／X 8本／Facebook 3本）＋ハッシュタグ |
| `posting-plan.md` | 4週間の投稿計画と運用ルール |

## 前提（要確認）

本文は以下を仮置きして書いています。違っていれば教えてください。該当箇所を書き直します。

1. 「住まいの対話」＝ HANDS-A-DESIGN が行う、**図面を描く前に住まい手とじっくり話す時間**を中心に据えた家づくりの進め方（＝サービス／取り組みの名前）
2. 対象は新築・リノベーションの両方
3. 相談は**無料または低額**で、その場で契約を迫らない
4. 発信主体は HANDS-A-DESIGN の公式アカウント

## 差し替えが必要なプレースホルダ

投稿文中の `【　】` は実情報に置き換えてください。

- `【アカウント名】` … 公式SNSのID
- `【エリア】` … 対応エリア（例：東京・神奈川）
- `【相談方法】` … オンライン／来店／出張など
- `【リンク】` … サイトURL（プロフィールリンクに置く場合は文面から削除）
- `【実例】`『【　】』 … 実際にあったお客様の言葉・エピソード

> エピソード枠は**実話に差し替えることが前提**です。仮の文例のまま投稿しないでください。
