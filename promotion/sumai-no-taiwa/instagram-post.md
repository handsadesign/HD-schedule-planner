# Instagram投稿：「住まいの対話」リリース告知

sumai-dialogue.com の紹介投稿。目的は認知拡大。

## 1枚目の文言

```
「どんな家にしたいですか？」に、
すぐ答えられなくていい。
```

### 別案
- 設計者に会う前に、話しておきませんか。
- 岡山の方にも、愛知の方にも、渡せるものができました。
- あなたの暮らしの言葉を、一冊にします。

## 本文

```
「住まいの対話」というウェブサービスをつくりました。

AIの聞き手と話しながら、自分の暮らしの価値観を整理していくと、
最後に「暮らしと住まいの要望書」という一冊にまとまります。
スマートフォンでもパソコンでも使えます。

日々リノベーションのヒアリングをしていて、
ずっと感じてきたことがあります。

「どんな家にしたいですか？」と聞かれて、
すぐに答えられる方は、ほとんどいません。
当然です。家づくりは一生に一度あるかどうかで、
考える練習をする機会がないまま、
打ち合わせの席に着くことになるからです。

設計者は、言葉をたくさん持っています。
住む方は、たぶん初めて。
同じテーブルに着いても、会話はどうしても設計者の側に傾きます。
私たちがどれだけ気をつけても、この傾きそのものは消えません。

だったら、住む方の側に、あらかじめ言葉を用意してもらえばいい。
設計者に会う前に、自分の暮らしとゆっくり向き合う時間があればいい。
そう考えて作りました。

もうひとつ、きっかけがあります。
これまでに岡山や兵庫、愛知など、遠くからご相談をいただくことがありました。
建築は場所に根ざす仕事で、なかなかお応えできませんでした。
けれど、建てるという責任からは離れて、
ヒアリングで培った経験と知識だけなら、距離を越えて届けられる。
そう気づきました。

できあがった要望書は、対話をした方のものです。
私たちに持ってきていただいても、
他の設計者さんや工務店さんとの打ち合わせに使っていただいても、
誰にも見せずにしまっておいても構いません。
サービスの中から私たちへの誘導は一切ありませんし、
話した内容が私たちに届くこともありません。
（対話の記録はサーバーに保存されず、ご本人の端末の中にだけ残ります）

一気に進めれば1時間ほど。
途中で止めても、続きから再開できます。
急がず、暮らしながら考えるくらいがちょうどいいと思います。

これから家づくりやリノベーションを考えている方は、
誰かに会う前に、一度試してみてください。
相手が私たちであっても、別の設計者さんであっても、
自分の言葉を持って席に着くのとそうでないのとでは、
打ち合わせの深さが変わります。

▷ sumai-dialogue.com

#住まいの対話 #家づくり #リノベーション #家づくりのはじめ方 #暮らしを考える
```

## メモ

- キャプション内のURLはリンクにならないため、**プロフィールのリンクにも sumai-dialogue.com を設定**すること
- 「音楽や物語は作り手の手を離れて届くのに、建築はそうならない」という一節は、投稿では省いた。良い部分だが尺に対して本筋（遠方の方に渡せるものができた）がぼやけるため、**別投稿として単独で立てるほうが効く**
- トーンは意図的に静かなまま。煽らない書き方が「誘導しない」というサービスの設計思想と一致しているため
