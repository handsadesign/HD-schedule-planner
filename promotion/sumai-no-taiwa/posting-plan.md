# 投稿計画（4週間）

認知拡大が目的なので、**頻度より一貫性**を優先します。週2本を4週間続けるだけで、`#住まいの対話` に十数本たまります。

## 4週間の並べ方

| 週 | 曜日 | 媒体 | 内容 |
| --- | --- | --- | --- |
| 1週目 | 火 | Instagram | ① 名前の説明「図面の前に、話をしよう。」 |
| | 木 | X | 1) 住まいの対話とは |
| | 金 | ストーリーズ | A アンケート型 |
| 2週目 | 火 | Instagram | ② 「まだ早い」を外す |
| | 木 | X | 2) まだ決めてない前置き ／ 8) 敷居が高い |
| | 土 | Facebook | F1 サービス紹介 |
| 3週目 | 火 | Instagram | ③ 夫婦で話す5つの質問（**保存狙いの主力**） |
| | 木 | X | 4) 建てる前に割れたほうがいい ／ 6) 決める前にそろえる |
| | 金 | ストーリーズ | B 質問箱 → 届いた質問は次週のネタに |
| 4週目 | 火 | Instagram | ④ 実際の対話から（※実話に差し替え） |
| | 木 | X | 3) 広いリビング ／ 7) 理想は言えない |
| | 土 | Facebook | F2 読みもの型 |

| 予備 | | ストーリーズ | C 舞台裏 ／ D 再掲 |

投稿時刻の目安：Instagram フィードは **20〜22時**、X は **7〜8時／12時台**、Facebook は **土日の朝**。

## 運用ルール

1. **`#住まいの対話` を必ず全投稿に入れる。** 例外なし。ここが積み上がりのすべてです
2. **売り込みは3回に1回まで。** 残り2回は読んで終わりでいい内容にする
3. **1枚目の文字は1文だけ。** 情報を詰めると読まれません
4. **エピソード投稿は実話のみ。** 作り話を1本入れた時点で全体の信用が消えます。お客様の許可も必ず取る
5. **コメント・DMには24時間以内に返す。** 認知フェーズでは反応の速さがそのまま印象になります

## 2か月目以降のネタ切れ対策

同じ3本柱（`concept.md` 参照）から、切り口を変えて出し続けられます。

- 質問リスト型：「土地を見に行く前に確認したい5つのこと」「リノベか建て替えかで迷ったときの判断材料」
- 舞台裏型：対話のあとのメモ、手描きスケッチ、模型づくり
- Q&A型：ストーリーズの質問箱に届いたものへの回答
- 季節もの：「夏の暑さで気づいた住まいの不満、覚えておいてください」
- 記録型：`#住まいの対話` が◯本たまりました、という節目の投稿

## 効果の見かた（認知フェーズの指標）

申込数はまだ追わなくて構いません。見るのはこの3つです。

- **保存数**（Instagram）… 内容が役に立ったかの一番素直な指標
- **リーチのうちフォロワー外の割合**… 新規に届いているか
- **`#住まいの対話` の投稿数・検索されているか**… 名称そのものが認知されつつあるか

3か月続けて、保存数が伸びている型を主力に寄せていってください。
