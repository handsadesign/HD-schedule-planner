## 1. 前提整理

### 確認済みの既存アセット(2026-08 調査)

- **HP**: hands-a-design.jp — 相談ページ(/renovation/)・施工事例(their-home)・私たちの家(/myhome/)・Event&News(完成見学会/土曜相談会)・ブログが稼働中
- **拠点/商圏**: 千葉県船橋市。夫婦の一級建築士事務所。対応エリアは千葉・埼玉・東京・神奈川
- **Pinterest**: アカウント有・フォロワー約1,800人。ただし他者ピンの保存が中心 → 自社事例のリンク付きピン化が伸びしろ
- **YouTube**: チャンネル有(テーマ:建築家夫婦の自宅と暮らし)。Shorts流用の受け皿は準備済み
- **プロモ動画の家 = HP「私たちの家」**(2012年に築26年・72㎡をスケルトンリノベした自宅)。動画→HPのストーリーが一直線につながる

- 商材の性質: **検討期間が長い**(数ヶ月〜数年)・**商圏が限られる**・**ビジュアルで選ばれる**・単価が高く1件の価値が大きい
- 体制: 少人数。使える時間は限られる → **「1ソース・マルチユース」を全チャネルの原則にする**
- 強み: 木の質感で統一された竣工写真の蓄積 / 実例(川口Fさんの家 等)/ 「住まいの対話」などの言葉のコンテンツ / **定期開催している完成見学会・相談会(強力な誘い文句)**

## 2. 全体設計:検討段階×チャネルの役割

```
[① 知る(認知)]      Instagram / Pinterest / YouTube Shorts
        ↓                 ※同じ動画・画像を3媒体に配信
[② 調べる(検討)]    ホームページ事例ページ / note / YouTube本編
        ↓                 ※検討期の長い客が「読む・見返す」場所
[③ 行動(相談)]      Googleビジネスプロフィール / Google検索広告 / 無料相談会
                          ※「地域名×リノベ」で今まさに探している人を拾う
```

原則: **①で興味 → ②で信頼 → ③で申込**。どのチャネルも最終的に「無料相談会ページ」へ誘導する。

## 3. チャネル別の方針

### Instagram(認知の主戦場)
- Instagram運用計画書に従う(月3〜4投稿・地域指定ブースト・受け皿整備)

### Pinterest(仕込んだら勝手に働く「資産型」)
- 特性: 投稿が**数ヶ月〜数年検索され続ける**。ピンに直接リンクを張れる唯一のSNS。住まい系ユーザー比率が高い
- やること:
  - リール動画をそのまま投稿(済の分から順次)
  - **カルーセルの各枚をバラして1枚ずつピン化**(1カルーセル=6〜10ピンになる)
  - 各ピンのリンク先は該当する事例ページ(なければHPトップ)
  - ボードを「キッチン」「収納」「木の家」「Before/After」などテーマ別に整理
- 頻度: 月1回、Instagramで使った素材をまとめてピン化(30分作業)
- 広告は当面不要。オーガニックの検索流入だけで費用対効果が成立する

### YouTube(信頼構築。二段構え)
- **Shorts(今すぐ)**: リール動画をそのまま流用。タイトルにコピーを入れる。説明欄にHPリンク
- **本編=ルームツアー(半年以内に検討)**: 3〜5分の事例ルームツアーは、検討後期の客が「この会社に頼むか」を判断する材料として最も効く。iPhone+ジンバルで内製可能。まず1本試作し、反応を見て継続判断
- チャンネル整備: 概要欄・リンク・チャンネルアートを先に整えておく(Shorts流用だけでも受け皿になる)

### Googleビジネスプロフィール(無料で最優先)
- 「◯◯市 マンションリノベーション」の地図検索・ローカル検索に出る枠。**無料**
- やること:
  - 未登録なら即登録、登録済みなら情報を最新化(営業時間・カテゴリ・HP・写真)
  - 竣工写真を20枚以上掲載
  - **引き渡し済みの施主にクチコミを依頼**(2〜3件入るだけで地域内の見え方が激変する)
  - 月1回、投稿機能で事例を1件アップ
- 費用ゼロで「③行動」層に届く、優先度最上位の施策

### Instagram広告(ブースト)の確定設定
- 誘導先: **hands-a-design.jp/event/640.html(相談会ページ)**
- 地域: **船橋市を中心に市川・習志野・千葉市・江戸川区・浦安など来訪可能圏**。対応エリア(1都3県)全域には広げない — 薄まるため
- **完成見学会の告知投稿は最優先のブースト対象**。「日程あり・組数限定」は相談会より申込ハードルが低く広告と最も相性が良い。開催2〜3週間前から地域ブースト

### Google検索広告 → 保留(2026-08-24 判断)
- AI検索の普及でクリック型検索広告の価値は低下傾向。GA4でも既にAI Assistant経由の流入を確認
- **AI時代の投資先は広告ではなく「AIとGoogleが引用する情報源」**= Googleビジネスプロフィール・クチコミ・HPの明確な事例情報。ここに注力する
- 見学会サイクルが1年回っても集客が足りない場合のみ、2027年に月2〜3万円でテストを検討(開始条件: 申込フォーム+GA4キーイベント計測)

### note(検討期の深い読み物。2アカウント体制で運用中)
- **note.com/hands_takako**(星名貴子・個人名義): 暮らしと事例の物語=実質ブログ。検討中期の信頼育成
- **note.com/idea_handsdesign**: 自社開発サービス「住まいの対話」の思想・紹介
- 2アカウント分離は維持(人格の記事とサービスの記事は読者層が違う)。相互リンクは張る
- 月1本ペースで十分。**各記事末尾に定型導線**: takako側=事例(HP)・見学会情報/idea側=住まいの対話を試す
- noteはドメインが強く検索に載りやすい。「船橋 リノベーション」系の読み物はnote側が有利な場合もある
- 12月見学会の温め期間(9〜11月)に、会場の家にまつわる記事をtakako名義で1本(Instagram・note・HPの物語を揃える)

### 住まいの対話(中間段階の受け皿。既存アセット)
- AIと対話して住まいの要望書をつくる自社開発サービス(無料から)。**「相談会はまだ早いが興味はある」層への、一番軽い行動の選択肢**
- 戦略書初版でLINE公式に想定していた役割を、既にこのサービスが担える → LINE導入の優先度は下げる
- **位置づけの原則**: 「誰にも送客しない」という思想が価値の核。集客装置として露骨に使わず、**信頼をつくるブランド資産**として扱う(使った人が自然にハンズデザインを覚え、信頼する流れで十分)
- Instagramプロフィールのリンクは3ボタン構成に: 「施工事例を見る」「見学会・相談会」「住まいの対話(無料)」

### LINE公式アカウント(将来の検討候補)
- 検討期間が長い業種のため「相談会はまだ早いが、繋がっておきたい」層の受け皿として有効
- 導入は Phase 3(半年後)に判断。それまでは保留

## 3.9 運用リズム(これだけ回せば全部つながる)

**原則: すべての発信は「次の見学会」を軸にした3ヶ月サイクルに乗せる。年4回開催=このサイクルを年4周するだけ。**

### 四半期サイクル(1見学会=1周)

```
1ヶ月目(3ヶ月前) : 会場の家の投稿1〜2本(施工中・素材)+note記事1本(takako名義・その家の物語)
2ヶ月目(2ヶ月前) : 完成カルーセル+「見学会やります」予告(日程未発表)
3ヶ月目(1ヶ月前) : 正式告知+申込開始+地域ブースト/ストーリーズでカウントダウン
開催直後          : 事後レポート投稿 → そのまま次の周の1ヶ月目へ
```

- Instagram月3〜4投稿のネタはこのサイクルでほぼ埋まる(足りない月は過去事例の束ね直しカルーセル)
- Pinterest・YouTube Shortsは「Instagramに出したものを流すだけ」(追加制作なし)
- 広告費を使うのは**告知期(1ヶ月前〜開催)に集中**。平時のブーストは反応が良かった投稿だけ

### 週次リズム(ミニマム版・月4〜6時間)

| 週 | やること(月内で1回ずつ) |
|---|---|
| 第1週 | 今月分の投稿2本をまとめて制作(リール1+カルーセル1)+予約投稿セット+各回Shorts転載 |
| 第2週 | note記事(**四半期に1本**・見学会の会場の家の物語。ない月はスキップ) |
| 第3週 | Pinterest月1バッチ: 月10〜15ピンを作成し、予約投稿で2〜3日おきに配信されるようセット(30分) |
| 第4週 | 月次レビュー10分(保存数・プロフィールアクセス・リンクタップ・問い合わせ経路)+翌月の題材決め |

※YouTubeルームツアー本編は2年目に再検討(当面はShorts転載のみ)

### やらないことで効率を守る

- 見学会サイクルに関係ない単発ネタを追わない(トレンド・時事は原則スルー)
- 平時の広告、全チャネル同時強化、毎日投稿はしない
- 数字はKPI4つ以外を追わない(ビュー数・フォロワー数に一喜一憂しない)
