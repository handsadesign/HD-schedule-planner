# プロモーション全体戦略書

作成日: 2026-08-23
対象: ハンズデザイン一級建築士事務所(マンションリノベーション)
関連文書: プロモーションビデオ企画書 / Instagram運用計画書(同フォルダ)

## 1. 前提整理

### 確認済みの既存アセット(2026-08 調査)

- **HP**: hands-a-design.jp — 相談ページ(/renovation/)・施工事例(their-home)・私たちの家(/myhome/)・Event&News(完成見学会/土曜相談会)・ブログが稼働中
- **拠点/商圏**: 千葉県船橋市。夫婦の一級建築士事務所。対応エリアは千葉・埼玉・東京・神奈川
- **Pinterest**: アカウント有・フォロワー約1,800人。ただし他者ピンの保存が中心 → 自社事例のリンク付きピン化が伸びしろ
- **YouTube**: チャンネル有(テーマ:建築家夫婦の自宅と暮らし)。Shorts流用の受け皿は準備済み
- **プロモ動画の家 = HP「私たちの家」**(2012年に築26年・72㎡をスケルトンリノベした自宅)。動画→HPのストーリーが一直線につながる

- 商材の性質: **検討期間が長い**(数ヶ月〜数年)・**商圏が限られる**・**ビジュアルで選ばれる**・単価が高く1件の価値が大きい
- 体制: 少人数。使える時間は限られる → **「1ソース・マルチユース」を全チャネルの原則にする**
- 強み: 木の質感で統一された竣工写真の蓄積 / 実例(川口Fさんの家 等)/ 「住まいの対話」などの言葉のコンテンツ / **定期開催している完成見学会・相談会(強力な誘い文句)**

## 2. 全体設計:検討段階×チャネルの役割

```
[① 知る(認知)]      Instagram / Pinterest / YouTube Shorts
        ↓                 ※同じ動画・画像を3媒体に配信
[② 調べる(検討)]    ホームページ事例ページ / note / YouTube本編
        ↓                 ※検討期の長い客が「読む・見返す」場所
[③ 行動(相談)]      Googleビジネスプロフィール / Google検索広告 / 無料相談会
                          ※「地域名×リノベ」で今まさに探している人を拾う
```

原則: **①で興味 → ②で信頼 → ③で申込**。どのチャネルも最終的に「無料相談会ページ」へ誘導する。

## 3. チャネル別の方針

### Instagram(認知の主戦場)
- Instagram運用計画書に従う(月3〜4投稿・地域指定ブースト・受け皿整備)

### Pinterest(仕込んだら勝手に働く「資産型」)
- 特性: 投稿が**数ヶ月〜数年検索され続ける**。ピンに直接リンクを張れる唯一のSNS。住まい系ユーザー比率が高い
- やること:
  - リール動画をそのまま投稿(済の分から順次)
  - **カルーセルの各枚をバラして1枚ずつピン化**(1カルーセル=6〜10ピンになる)
  - 各ピンのリンク先は該当する事例ページ(なければHPトップ)
  - ボードを「キッチン」「収納」「木の家」「Before/After」などテーマ別に整理
- 頻度: 月1回、Instagramで使った素材をまとめてピン化(30分作業)
- 広告は当面不要。オーガニックの検索流入だけで費用対効果が成立する

### YouTube(信頼構築。二段構え)
- **Shorts(今すぐ)**: リール動画をそのまま流用。タイトルにコピーを入れる。説明欄にHPリンク
- **本編=ルームツアー(半年以内に検討)**: 3〜5分の事例ルームツアーは、検討後期の客が「この会社に頼むか」を判断する材料として最も効く。iPhone+ジンバルで内製可能。まず1本試作し、反応を見て継続判断
- チャンネル整備: 概要欄・リンク・チャンネルアートを先に整えておく(Shorts流用だけでも受け皿になる)

### Googleビジネスプロフィール(無料で最優先)
- 「◯◯市 マンションリノベーション」の地図検索・ローカル検索に出る枠。**無料**
- やること:
  - 未登録なら即登録、登録済みなら情報を最新化(営業時間・カテゴリ・HP・写真)
  - 竣工写真を20枚以上掲載
  - **引き渡し済みの施主にクチコミを依頼**(2〜3件入るだけで地域内の見え方が激変する)
  - 月1回、投稿機能で事例を1件アップ
- 費用ゼロで「③行動」層に届く、優先度最上位の施策

### Instagram広告(ブースト)の確定設定
- 誘導先: **hands-a-design.jp/renovation/**(相談ページ)
- 地域: **船橋市を中心に市川・習志野・千葉市・江戸川区・浦安など来訪可能圏**。対応エリア(1都3県)全域には広げない — 薄まるため
- **完成見学会の告知投稿は最優先のブースト対象**。「日程あり・組数限定」は相談会より申込ハードルが低く広告と最も相性が良い。開催2〜3週間前から地域ブースト

### Google検索広告(行動層の刈り取り。受け皿完成後に)
- 対象キーワード: 「マンションリノベーション 船橋」「リノベーション 相談 千葉」など**今探している人**の検索語
- 特性: クリック単価は高め(リフォーム系は1クリック300〜1,000円)だが、意図が最も濃い
- 開始条件: **相談会のランディングページ(申込フォーム付き)が整ってから**。受け皿なしで出すとInstagramの「数字買い」の再演になる
- 予算: 月2〜3万円でテスト → 問い合わせ単価(広告費÷相談件数)で継続判断
- ディスプレイ広告・P-MAXは当面やらない(認知はSNSで足りる)

### note(検討期の深い読み物。既存の流れを継続)
- 「住まいの対話」的な、思想・プロセスを伝える記事は検討後期の後押しに効く
- 月1本ペースで十分。各記事の末尾に相談会への導線を必ず入れる
- 記事はHPのブログ/コラムにも転載し、SEO資産にする

### LINE公式アカウント(将来の検討候補)
- 検討期間が長い業種のため「相談会はまだ早いが、繋がっておきたい」層の受け皿として有効
- 導入は Phase 3(半年後)に判断。それまでは保留

## 3.5 見学会プレイブック(プロモーションの中心エンジン)

**根拠**: 2026年7月、見学会2件の開催期間にHPアクセスが通常の3〜4倍(1日約1,000ユーザー)に跳ね、問い合わせも発生。投稿・広告単体より見学会が最も成果に直結している。

**基本サイクル(年4回開催=3ヶ月で1周)**: 申込受付は1ヶ月前(現行どおり)。ただし"温め"は3ヶ月前から始める。

| タイミング | やること |
|---|---|
| 3ヶ月前〜 | 会場になる家の施工中カット・素材・工夫を通常投稿として出す(「見学会」とはまだ言わない) |
| 2ヶ月前 | 完成カット投稿+「近々この家で見学会を予定」と予告のみ(日程未発表・期待づくり) |
| 1ヶ月前 | **正式告知+申込開始**。告知投稿(カルーセル: 1枚目=会場の家のヒーローカット+日程、中身=見どころ・間取り・アクセス)+HPのEvent&Newsに掲載 |
| 3〜2週間前 | **告知投稿を地域ブースト開始**(船橋中心・1日500〜1,000円・誘導先=イベントページ)。リールがあれば会場の家の動画も投稿 |
| 1週間前 | ストーリーズで「残り◯組」カウントダウン+リンクスタンプ。固定コメントにも申込導線 |
| 前日〜当日 | ストーリーズで会場準備の様子(ライブ感) |
| 開催後1週間以内 | **事後レポート投稿**(当日の様子・来場者の声)。「次回開催の先行案内はプロフィールから」で次につなげる |

- 申込は必ずフォームで受け、「何で知りましたか?」を設問に入れる
- 年4回開催(約3ヶ月間隔)のため、「事後レポート→次会場の投稿→予告→告知」で1サイクル3ヶ月が回る。**月3〜4投稿のネタはこのサイクルでほぼ埋まる**

### 次回開催(2026年12月中旬)に向けた実スケジュール

| 時期 | やること |
|---|---|
| 9月 | 会場になる家の投稿を開始(施工中カット・素材・工夫)。並行して川口Fさんの家カルーセル等の通常投稿 |
| 10月中旬 | 完成カット投稿+「12月にこの家で見学会を予定しています」と予告(日程は未発表でよい) |
| 11月中旬 | **正式告知+申込開始**(告知カルーセル+Event&News掲載)。ブースト開始(船橋中心・誘導先=イベントページ) |
| 12月上旬 | ストーリーズでカウントダウン・残り組数 |
| 12月中旬 | 開催。当日の様子をストーリーズ |
| 12月下旬 | 事後レポート投稿+「次回の先行案内はプロフィールから」 |

## 4. 実行ロードマップ

### Phase 0: 受け皿づくり(〜1ヶ月)★最優先
- [ ] Googleビジネスプロフィールの登録・充実・クチコミ依頼
- [ ] HPに「無料相談会」ページ(申込フォーム付き)を用意

## 6. 月次で見る数字(チャネル横断)

| チャネル | 指標 |
|---|---|
| Instagram | 保存数・プロフィールアクセス・リンクタップ |
| Pinterest | ピンのクリック数(=HP流入) |
| YouTube | Shorts再生・チャンネル登録 |
| Googleビジネスプロフィール | 表示回数・ルート/電話/サイトのアクション数 |
| Google広告 | クリック単価・問い合わせ単価 |
| 最終 | **無料相談会の申込数と、その経路** |

申込フォームに「何で知りましたか?」の設問を必ず入れ、経路を記録する。

## 7. やらないことリスト(重要)

- ターゲット自動・再生数目的のSNS広告(実績: 24,425ビュー→プロフィール7人)
- 全チャネルを同時に立ち上げること(Phase順に。手が回らなくなったらPhaseを戻す)
- X(Twitter)・TikTok(ターゲット層との相性と工数を考え当面見送り)
- ディスプレイ広告・チラシ大量配布などの広域認知施策(商圏ビジネスには非効率)
